# Gestion.des.affectatons.des.employes
Application de gestion des affectations d'employés développée avec Spring Boot (backend/API REST) et Java Desktop (client Swing/JavaFX), connectée à une base MySQL. Gère les employés, les lieux d'affectation et l'historique des affectations, avec CRUD complet et recherche d'employés par code ou nom.
